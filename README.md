# 📚 TokoBukuKita — Web Jual Beli Buku Online

**TokoBukuKita** adalah aplikasi web jual beli buku berbasis **Vue.js** yang memungkinkan pengguna untuk menjelajahi, mencari, dan membeli berbagai jenis buku dengan antarmuka modern. Aplikasi ini dibangun untuk keperluan pembelajaran dan tugas akhir mata kuliah Pemrograman Berbasis Kerangka Kerja (PBK).

---

## 🚀 Fitur Unggulan

- 🔐 Login & manajemen akun pengguna (opsional)
- 📚 Daftar buku berdasarkan kategori
- 🔎 Pencarian dan pengurutan produk
- 🛒 Keranjang belanja & tombol tambah
- 👁️ Modal quick view untuk melihat detail buku
- 🎨 Tampilan responsif dan modern
- 💬 Notifikasi menggunakan Vue Toastify

---

## 🧰 Teknologi yang Digunakan

- [Vue.js 3](https://vuejs.org/)  
- [Vite](https://vitejs.dev/)  
- [Pinia](https://pinia.vuejs.org/)  
- [Vue Router](https://router.vuejs.org/)  
- [Font Awesome](https://fontawesome.com/)  
- [Vue3 Toastify](https://vue3-toastify.js.org/)  

---

## 📁 Struktur Folder

src/
├── assets/ # Gambar, ikon, background
├── components/ # Komponen UI seperti ProductCard.vue
├── views/ # Halaman utama (Home.vue, Products.vue, dst.)
├── stores/ # State management dengan Pinia
├── router/ # Routing dengan Vue Router
├── App.vue # Root component
└── main.js # Entry point aplikasi

## ⚙️ Cara Menjalankan Proyek

### 1. Clone Repository

```bash
git clone https://github.com/yookaaa/tugas-PBK-pertemuan10/tree/UAS
cd PBK-pertemuan10

2. Install Dependensi
npm install

3. Jalankan di Mode Pengembangan
npm run dev

4. Build untuk Produksi
npm run build
